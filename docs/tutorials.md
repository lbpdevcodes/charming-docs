# Tutorials

Learn Charming by building real apps, start to finish. Each tutorial is a full
walkthrough — every command and every file — built "the Charming way" with the
generators and tools the framework ships. Work through them in order; they grow
from a single screen to richer, multi-screen apps.

Where [Getting Started]({{ '/docs/getting-started/' | relative_url }}) tours a
generated app and the [Journal example]({{ '/docs/example-app/' | relative_url }})
shows a finished reference, these tutorials sit in between: you type the commands
and write the code yourself.

| Tutorial | You'll build | You'll learn |
|----------|--------------|--------------|
| [Build a TODO App]({{ '/docs/tutorials/todo/' | relative_url }}) | A persistent todo TUI backed by SQLite | `charming new --database sqlite3`, models & migrations, the `db:*` commands, a list + text input, key bindings, the focus ring, a status bar, and journey specs |

More tutorials are on the way. Each one introduces a few new framework features
while reinforcing the fundamentals from the ones before it.
