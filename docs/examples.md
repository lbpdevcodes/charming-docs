# Examples

Complete, runnable apps built with Charming. Where the
[tutorials]({{ '/docs/tutorials/' | relative_url }}) walk you through typing
every line yourself, these are finished apps to read, run, and borrow from.

| Example | What it is |
|---------|------------|
| [Journal]({{ '/docs/example-app/' | relative_url }}) | The reference app: a daily-writing TUI that exercises every major framework feature. Lives in the framework repo. |
| [Hacker News]({{ '/docs/examples/hackernews/' | relative_url }}) | The reader from the landing page: six feeds, inline article reading, async loading. Ships as the [`hackernews`](https://rubygems.org/gems/hackernews) gem. |
| [Pac-Man]({{ '/docs/examples/pacman/' | relative_url }}) | An arcade clone with sprites, ghost AI, and SQLite high scores. Ships as the [`pacmanrb`](https://rubygems.org/gems/pacmanrb) gem. |
